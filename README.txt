Kicia Runner — wersja free-play

1. Otwórz index.html lokalnie albo wrzuć całą zawartość folderu na GitHub Pages.
2. Na początku wybierasz postać: Rufi, Ona + Rufi albo jeden z czterech kotów.
3. Wybór postaci i rekord zapisują się w localStorage przeglądarki.
4. Sterowanie: dotknięcie/kliknięcie/spacja = skok.
5. Mapy zmieniają się automatycznie co ok. 23 sekundy.
6. Na razie brak leveli i blokad — wszystkie postacie są dostępne.
